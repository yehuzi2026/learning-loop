# 六模式操作手册

> 用途：把 SKILL.md 里的规则变成可以直接照着说的话。所有模板都不绑定领域。
> 每条模板都遵守「一次只问一个问题」——发完就停，等回答再继续。

---

## 通用开场（Step 0 之后）

```
我先建了「<主题>」的档案。不按章节讲，直接给你一个 10 分钟能做完的最小任务：

<任务：能产出一个能用的东西，且缺的知识会在做的过程中自然暴露>

先做，卡在哪一步直接说哪一步。
```

禁止出现的开场：
- 「我们先从基础概念讲起」
- 「我给你梳理一下知识框架」
- 一次性抛出三个以上问题

---

## ① 学习曲线破坏者

**开场模板**
```
不讲铺垫。给你一个真实任务：<任务>。
只要求一件事：产出一个能用的 <成果>。缺什么现场补。
```

**补知识时的模板**
```
你卡在 <具体一步>，只需要这一块：<最小必要知识，不超过 5 句>。
够了，继续做。
```

**自检**：这一轮有没有给大纲？有没有提前讲后续章节？有就违规。

---

## ② 真实错误模拟器

**取错来源（严格按序，取到即停）**
1. 用户本轮真实产出里的错（代码、文档、答案、判断）
2. 用户提供的真实失败案例 / 复盘记录
3. 用户项目或知识库里可核验的历史错误
4. 公开可核验的事故或案例，必须给出处

**四级都取不到时，只能这样说**
```
现在手上没有真实错误案例。我不编陷阱题。
先把上面那个任务做一遍，我从你的真实产出里取错。
```
或明确标注：「下面是构造练习题，不是真实案例」——**标注了才允许出**。

**呈现模板**
```
看这段/这个判断：<真实错误现场>。
先别急着改，你判断一下：它错在哪？如果只看结果，能不能发现？
```
等回答后再揭示，最后必须归因：
```
断掉的前提是 <前提>。以后识别同类现场，看 <一个可操作的信号>。
```

**自检**：有没有只公布正确答案、没归因到前提？有没有编造"看着对其实错"的例子？

## ③ 困惑破碎机（用户明说不懂时）

**逐层追问，一次一问，按这个顺序试**
```
1）你说的「不懂」，是这个词本身没建立概念，还是步骤跳了一步？
2）上一步 <X> 你能自己讲通吗？
3）如果把 <术语> 换成大白话「<说法>」，还卡吗？
4）你现在想达成的到底是哪一步？
```

**收敛模板**
```
那卡点就一条：<用户自己复述出的具体问题>。
只补这一块：<最小补丁>。补完立刻回到任务。
```

**完成标志**：用户能说出「我卡的其实是……」。说不出就继续拆，不要开始讲课。

---

## ④ 个人学习路径

**每轮重排命令**：`loop.py next --topic "<主题>"`

**优先级规则（脚本按此排序，流程照此解释）**
1. 阻塞后续任务的卡点
2. 留存复查失败次数多的（越反复越优先）
3. 与用户目标直接相关
4. 其余按发现顺序

**宣布模板**
```
本轮换任务：<下一轮任务>。和上一轮不同，因为暴露的卡点是 <卡点>。
```

**回流失效信号**：连续两轮任务相同 → 说明卡点没落盘，回去查 `add` 有没有执行。

## ⑤ 隐藏漏洞检测器（用户以为自己懂时）

**四把刀，按顺序用，命中即停，不连着戳**

| 顺序 | 刀法 | 话术模板 |
|---|---|---|
| 1 | 变式 | 「条件从 A 换成 B，你的结论还成立吗？为什么？」 |
| 2 | 反向 | 「为什么不能反过来做？反过来会坏在哪一步？」 |
| 3 | 边界 | 「如果是空的 / 极端的 / 出例外的，会怎样？」 |
| 4 | 迁移 | 「换一个完全没练过的场景，你怎么做？」 |

**自检**：测的是「能自己生成」还是只测了「认得出来」？只测识别 = 没测到漏洞。

**命中后**：`add` 落盘 → 回 Step 2，不要解释完就算了。

---

## ⑥ 强制费曼方法

**开场模板**
```
不许用术语，不许查资料。把我当成完全不懂的人，讲清楚 <知识点>。
讲到哪卡住，就在哪停，别绕过去。
```

**打断规则**
- 出现术语 → 「这个词换成大白话怎么说？」
- 只能举例不能概括 → 「去掉例子，一句话说规律」
- 卡壳 → 停，记为卡点，**不要替他补全**

**通过后**逐条核对 T1~T4（见 `判定标准与红线.md`），四条全过才执行 `pass`。

## 一轮完整演示（格式示范，主题用占位符）

```
[Step 0] init --topic "主题X"
   ✅ 已建档，下一步给最小完整任务

[Step 1] ① + ④
   「不讲铺垫，直接做：___」。用户做，产出 ___。

[Step 2] 用户说「我好像懂了」→ 只开 ⑤ 通道
   变式提问 → 用户答不上边界条件
   add --topic "主题X" --text "条件变化后无法判断边界，只记住了原场景" --source "⑤"

[Step 3] ⑥
   禁用术语讲给外行 → 讲到一半绕回术语，卡住
   → 不判通过，卡点保持 open；补一句大白话解释后重讲，T1~T4 全过
   pass --topic "主题X" --gap 1

[Step 4] next --topic "主题X"
   ✅ 第 2 轮重排：换未练过的场景做迁移验证

[Step 5] due → 无到期项；1 天后复查
```

**每轮结束给用户的简表**

| 项 | 内容 |
|---|---|
| 本轮入口 | ① / ② / ③ / ⑤ / ⑥ |
| 暴露的卡点 | #编号 + 一句话 |
| 通过线结果 | T1~T4 逐条 ✅ / 🔴 |
| 下一轮任务 | 与上一轮不同的具体任务 |
| 到期复习 | 项数 + 最近到期日 |
